Proyectos

Proyecto 1

El proyecto consiste en el desarrollo de una plataforma web interactiva de nutrición inteligente, diseñada para calcular con precisión científica el consumo calórico diario y automatizar la planificación de dietas personalizadas. A diferencia de las herramientas genéricas de internet, este sistema integra algoritmos validados médicamente y un diseño centrado en el usuario (UX) para transformar datos corporales simples en planes de alimentación accionables, exactos y adaptados a los objetivos individuales de salud.

Proyecto 2

Es un diseño de una plataforma web de ahorro automatizado y finanzas personales. El sistema analiza los ingresos mensuales del usuario, sus gastos fijos y sus metas financieras (como comprar un auto o viajar), y calcula de forma automática un plan de presupuesto diario exacto, enviando alertas en tiempo real para evitar que la persona gaste de más.

Ver proyecto

Proyecto 3

Es un diseño de una aplicación web de entrenamiento inteligente para el gimnasio. El usuario ingresa sus datos físicos, sus días disponibles para entrenar y sus lesiones previas; con esto, el sistema calcula la carga de peso exacta, las repeticiones y los ejercicios ideales para cada sesión, adaptando la rutina automáticamente cada semana según su progreso real.
